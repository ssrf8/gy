# 卡面内容占位

- 设计权威：**source/card/玩法设计.md**（玩法、条目表、状态、开局流程）
- 本文件用于写卡阶段落稿：
  - 卡面身份字段：人物描述、性格、背景（关公）
  - 开场问候：按玩法设计 §5 的简短开局（含共享初始化，<initvar> 机制以真机核实为准）
  - 示例对话：玩法设计 §5 草稿润色
  - 守护灵条目正文（关羽 / 赵公明）、四家条目正文（王家 / 李家 / 张家 / 陈家）
  - 剧情 CoT：默认方案 = 预设主 CoT + 卡专属增量 + 条件模块（[mvu_plot]）
- 红线备忘：
  - 四家条目不写死神名（写「玉佩守护灵」）
  - 模型可见文本不含开发注释、事故史、装饰性 Markdown
  - 不复制预设完整 CoT，只写卡专属增量
  - 卡面文本与字段账本、世界书不重复表述同一内容
